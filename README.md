# SQL-Data-Analysis
# SQL for Data Analyst – Learning Journey

This repository contains my daily SQL practice as I learn SQL for a **Data Analyst** role — starting from zero, using MySQL Workbench.

## 🎯 Goal
To become confident in SQL for querying, filtering, and analyzing data stored in relational databases, in order to be job-ready for a Data Analyst role.

## 📅 Progress

### Phase 1: SQL Basics ✅
- **Day 1:** `CREATE DATABASE`, `USE`, `CREATE TABLE`
- **Day 2:** `INSERT INTO` — adding data to tables
- **Day 3:** `SELECT`, `DELETE FROM` — viewing and clearing data
- **Day 4:** `WHERE` — filtering data with conditions
- **Day 5:** `AND`, `OR` — combining multiple conditions
- **Day 6:** `ORDER BY` — sorting data (ascending/descending)
- **Day 7:** `LIMIT` — restricting number of results
- **Day 8:** Mini Project — Student Management Queries combining all basic concepts
